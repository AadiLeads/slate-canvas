# ATTRIBUTION

## Project and reference material

The project was developed independently as a SLATE AI canvas implementation.

The assignment's reference project, PenEcho, was used as architectural/reference inspiration as permitted by the assignment. No PenEcho source code or prompts were intentionally copied into this project.

Reference:
https://github.com/penecho/penecho

## Third-party libraries / services

The application uses its declared npm dependencies for canvas/UI/runtime functionality.

AI inference is accessed through OpenRouter using a multimodal Gemma model.

The project does not commit provider credentials.

All external material is used as reference/documentation, not as copied application source.
